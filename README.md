Çok mu fazla biletin var?

Hepsini organize edemiyor musun?

**Tek bir uygulamada birleştirdim. Bu kadar basit.**

Sonra trip duruyor karşında.

- Ne zaman başlıyor?
- Ne kadar erken gitmelisiniz?
